# Beta interna 0.1 — Diseño Multimedial

Checklist para 8–15 testers:

- [ ] Registrarse e iniciar sesión.
- [ ] Cargar un analítico PDF, CSV o TXT.
- [ ] Revisar las materias detectadas en Recorrido.
- [ ] Buscar una materia y verificar sus correlativas.
- [ ] Consultar el horario en Cátedras.
- [ ] Encontrar la próxima fecha académica en Agenda.
- [ ] Activar y desactivar un aviso.
- [ ] Abrir Cartelera y revisar una actividad.

Ante un problema, registrar dispositivo, navegador, ruta, hora aproximada y pasos para reproducirlo. No adjuntar contraseñas, cookies ni tokens.
